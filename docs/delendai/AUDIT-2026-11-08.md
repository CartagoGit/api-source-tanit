# Tanit audit — 2026-11-08

## MCP and proposal integrity

The project registration is `DelendAI:Tanit` in the canonical MCP configuration,
the generated VS Code configuration and all five agent grants. Launch uses the
installed DelendAI executable; the product remains independent of the optional
integration. The registration label does not change MCP tool names.

A real stdio smoke check completed initialize, tools/list and overview with the
Tanit plugin loaded. SIGTERM returned 143. The permission gate now recognizes
colons and rejects a grant to an unregistered project.

Ten archived proposals had unterminated YAML metadata; two also contained a
stray duplicate SHA list item. The repair restores delimiters and existing
shipped evidence from the generated index, preserving states and historical
content. Sixteen archived files now live in the folder declared by their kind.
The proposal gate now rejects a missing delimiter before a body heading.

## Local rename migration

Two obsolete Claude project registrations were merged under the current path.
Forty-two Copilot memory files were migrated to current names and paths; their
originals and the former cache-only project directory were archived before
migration. Recovery archives are in the user's cache under tanit-migrations.
Conversation transcripts, git history, release history and archived proposal
names remain historical records. This audit covers accessible local project,
host configuration, launchers, memory files and directory/symlink names; it does
not claim inspection of other disks or inaccessible operating-system stores.

## Shared authority

Contracts and framework-independent discovery/session services already exist.
The current CLI generation, legacy web handlers and app still have divergent
execution and history paths. Presentation adapters must consume the same
business services and canonical snapshots; scanners remain outside core and
DelendAI remains an optional integration.
